## 1. Human-in-the-Loop Review Workflow (`ui/app.py`)

The Streamlit dashboard enforces strict human authorization before any automated containment action is executed:

1. **Pending Review Queue**:
   All incident reports generated by the Multi-Agent Coordinator are queued for human adjudication.
2. **Interactive Visual Evidence Timeline**:
   Displays step-by-step telemetry events across `auth_logs`, `network_flows`, and `endpoint_logs`, each anchored by an immutable `evidence_id`.
3. **MITRE ATT&CK STIX Matrix View**:
   Renders identified adversary tactics, techniques, and sub-techniques.
4. **Action Adjudication Interface**:
   For every proposed remediation action (`isolate_host`, `block_ip`, `reset_credentials`):
   - **Approve**: Confirms the containment action for simulated execution.
   - **Reject**: Cancels the action (e.g. for approved penetration tests or maintenance).
   - **Modify**: Allows the analyst to adjust target entities or scopes.
   - Requires mandatory analyst justification notes.

## 2. Cryptographic Forensic Audit Trail (`backend/services/hitl_simulator.py`)

Every analyst review decision and simulated execution is cryptographically hashed and appended to an append-only JSONL log (`locals/logs/audit_trail.jsonl`):

```python
payload_to_hash = f"{review_id}|{report_id}|{action_type}|{target_entity}|{status}|{reviewed_by}|{timestamp}"
audit_hash = hashlib.sha256(payload_to_hash.encode("utf-8")).hexdigest()
```

### Forensic Properties:
* **Tamper-Evident**: Any alteration of past review decisions breaks the SHA-256 hash chain.
* **Non-Repudiation**: Binds the reviewer's authenticated identity (`reviewed_by`), exact timestamp, and justification.
* **Compliance Alignment**: Satisfies SOC 2 Type II, ISO 27001 (A.12.4.1 Event Logging), and NIST CSF (DE.DP-4) incident response audit requirements.
